# Проект «Оно тебе надо»

## Описание проекта

«Оно тебе надо» — веб-страница аукциона необычных вещей, выполненная с использованием HTML и CSS.

## Структура проекта

- `index.html` — HTML-разметка страницы.
- `fonts/`
  - `fonts.css` — подключение шрифтов.
- `styles/`
  - `global.css` — общие стили.
  - `style.css` — стили элементов страницы.
- `images/` — изображения, логотипы и иконки, используемые на странице.

## Что было сделано

1. **Создана структура HTML-страницы**
   - Добавлены шапка (`header`), основное содержимое (`main`) и подвал (`footer`).
   - Основное содержимое разделено на три секции: первый экран, карточки лотов и информация об аукционе.

2. **Оформлена шапка сайта**
   - Добавлено меню навигации.
   - Размещён логотип проекта.
   - Добавлена контактная информация: телефон, электронная почта и адрес.

3. **Создан первый экран**
   - Добавлен главный заголовок «Оно тебе надо».
   - Установлено фоновое изображение.
   - Добавлен полупрозрачный слой затемнения.
   - Размещены описание аукциона и кнопка «Сделать ставку».

4. **Создана секция с лотами**
   - Добавлены три карточки: фильм, книга и картина.
   - Для каждой карточки предусмотрены заголовок, описание и фоновое изображение.
   - Добавлена ссылка «Посмотреть больше».

5. **Создана секция «Об аукционе»**
   - Добавлен логотип проекта в круглом блоке.
   - Размещён заголовок секции.
   - Добавлено текстовое описание аукциона из двух абзацев.

6. **Оформлен подвал сайта**
   - Добавлена контактная информация.
   - Размещено меню навигации.
   - Добавлены ссылки на YouTube, ВКонтакте и Pinterest.

7. **Выполнена стилизация страницы**
   - Настроены шрифты, размеры текста, цвета и выравнивание.
   - Добавлены внешние и внутренние отступы.
   - Настроены фоновые изображения и затемнение.
   - Использованы Flexbox и Grid для расположения элементов.
   - Добавлены эффекты наведения и нажатия для кнопки.

8. **Использована методология БЭМ**
   - Классам присвоены понятные имена, например `header__menu`, `cover__title` и `lots__card-list`.
   - Для вариантов карточек использованы модификаторы `card_type_film`, `card_type_book` и `card_type_picture`.
